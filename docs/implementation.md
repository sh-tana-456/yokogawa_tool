## 全体構成

Pythonのみで動くQtデスクトップアプリです。UIはPySide6、波形描画はpyqtgraph、数値計算と配列の保存はNumPyを使います。専用のWebサーバーやブラウザは起動しません。

```text
WVF/HDR・CSV・セッション ─ waveform.load_file ─┐
                                             ├─ Trace配列 ─ MainWindow ─ メイン波形 / Overview
DL1640 ─ DL1640.capture / capture_live ─ Worker ┘                ├─ カーソル / 統計
                                                               ├─ Math / FFT
                                                               └─ セッション / CSV / PNG

DL1640のWeb画面 ─ screen.fetch_screen ─ 同じWorker ─ ScreenPanel（画像表示 / PNG保存）
```

## 波形データと読み込み

### `Trace`

名前、時刻配列 `x`、値配列 `y`、単位、色、表示状態、メタデータを持ちます。配列は浮動小数点に変換します。時刻は有限値・厳密な昇順で、2点以上、値配列と同じ長さが必要です。欠損値は `NaN` として保持し、描画時にその部分の線をつなぎません。

`Trace.nearest(time)` は `searchsorted` で最寄りサンプルを検索します。中間点での補間はせず、範囲外は時刻・値ともに `NaN`、同距離なら前のサンプルです。

CH欄には元サンプルの点数・間隔・記録時間を、小さめの英語ラベルで表示します。実機取得では `:TIMEBASE:TDIV?` / `:TIMEBASE:SRATE?` を各1回、表示CHの `VDIV?` を各1回照会し、`time_div` / `timebase_sample_rate` / `vertical_div` / `vertical_offset` / `vertical_range` をメタデータに保存します。`sample_rate` は従来どおり波形レコードのSRATEを保持します。divは照会時の設定であり、記録当時の設定とは限りません。既存ファイルにない値は推測しません。ライブ中は既存ラベルの文字列だけを更新します。

実機タブは設定照会の `sample_rate`（TIMEBASE由来）と、最後のレコードの点数・レート（WAVEFORM由来）を別キャッシュで保持します。選択CHのdivもCHごとに保持し、遅れて届いた別CHの設定を現在のCHとして表示しません。固定3行のサマリーを使い、値の変化でパネル幅や高さが動かないようにします。設定値の表示更新から本体への書込は行いません。

### WVF/HDR

`read_wvf()` は同じディレクトリから同名のWVFとHDRを探します。拡張子と名前の大文字・小文字は区別しません。

1. HDRのPublicInfoと各Groupを読み、DataOffset、Endian、DataFormat、トレース数、ブロック数を取得します。
2. Trace順またはBlock順に、各トレースのBlockSizeとVDataTypeでデータを切り出します。`IS1 / IS2 / IU1 / IU2 / FS4 / FS8` と旧実装の別名 `RF4 / RF8` に対応します。
3. 変換前の値でVIllegalData、VPlusOverData、VMinusOverDataを判定します。無効値・上限以上・下限以下は欠損扱いです。
4. `y = raw × VResolution + VOffset`、`x = HOffset + sample_index × HResolution` で実値に変換します。
5. CH順に並べ、複数ブロックは名前に `_B1` などを付けます。単位、元ファイル、ブロック、記録日時、機種を保持します。

WVF末尾の機器固有設定領域は波形として読みません。HUnitが秒以外の場合、項目不足、データ不足、不正な時間軸や重複名はエラーにします。

`export_wvf()` は[マニュアルAppendix 3](https://cdn.tmi.yokogawa.com/IM701610-01E.pdf)に従い、Big endian・Trace順・各トレース1グループ1ブロックのWVF/HDRを作成します。モデル名は `YOKOGAWA_TOOL` とし、DL1640本体の保存物とは区別します。FS8（8バイトの符号付き実数）でアプリ内のfloat64振幅を書き、VResolution=1、VOffset=0とします。NaN/±InfもIEEE浮動小数点として保存します。整数化・間引き・補間は行いません。元の整数コード・機器固有設定領域を再現する機能ではありません。

時間軸は開始値と両端から求めた刻み幅を17桁で出力します。元の全時刻と再構成時刻を比較し、許容差は刻み幅の1e-7と時刻の4 ULPの大きい方です。不等間隔なら拒否します。CHごとに点数・刻み幅は異なっていても構いません。名前・単位は空白のないASCII文字、名前は重複なしに制限します。

両ファイルの検証・一時ファイルへの書込後、同名の既存ファイルを退避して置換します。片方の置換が失敗した場合は元のペアへ復元を試みます。2ファイル全体がOS上の単一の原子的操作になるわけではありません。出力ダイアログは片方だけが存在する場合も上書きを確認し、既存拡張子の大文字・小文字を維持します。CSVと同じく解析状態の保存にはしません。

### CSV

`read_csv()` はUTF-8（BOM可）のカンマ区切りを読みます。空行と先頭が `#` の行は除外します。先頭列を秒の時刻、以降を波形とします。ヘッダの `CH1[V]` の角括弧から単位を読み、ヘッダなしではCH1以降・単位Vを割り当てます。

`export_csv()` は全CHの時刻の和集合を出力軸にし、該当時刻にサンプルがないCHには `nan` を入れます。非表示CHとMathも出力し、補間・再サンプリングはしません。

### セッション

`save_session()` / `load_session()` の形式はversion 1です。

| 形式 | 内容 |
|---|---|
| `.scope.npz` | `np.savez_compressed` の圧縮アーカイブ。`x0 / y0 / x1 / y1 …` の配列と、JSON文字列の `metadata` を格納。読み込みは `allow_pickle=False` |
| `.scope.json` | `format: dl1640-scope`、`version: 1`、`view`、`traces`。各トレースに配列と属性を格納。非有限の値は `null` で出力 |

波形配列、名前・単位・色・表示状態・メタデータと、表示範囲・A/B位置・テーマを保存します。元ファイルへのパスは履歴情報であり、再表示時に元ファイルを読む必要はありません。ホイール軸やアンチエイリアスなどのアプリ設定はQtの `QSettings("YokogawaTool", "WaveformWorkbench")` で別に保存します。パスワードは保存しません。

`load_file()` は拡張子から各ローダーに振り分けます。ファイルの読み書きとMathはGUIスレッドで実行し、通信のみをWorkerに分離しています。大きなファイルの展開・保存や重いMathでは、一時的に画面操作が待たされる場合があります。

## 表示範囲の復旧

`restore_view()` は保存されたX/Y範囲を適用する前に検証します。X範囲が有限の昇順2要素でない、表示波形と重ならない、または全波形の時間幅の20倍を超える場合、保存されたX/Y範囲を外して全体に合わせます。Y範囲だけが不正・データと重ならない場合はYだけを戻します。波形外のカーソル位置も外します。

通常のズームは維持します。`waveform_bounds()` は表示中の元配列から直接範囲を求め、表示中CHがない場合は範囲を返しません。Yがすべて欠損なら `−1〜1` を使います。「全体表示」はこの範囲に余白を付けて適用するため、間引き後の描画点が空でも復旧できます。元のセッションファイルは書き換えません。

## 描画と測定表

### 表示用の曲線補間

`WaveformPlotItem` は元のPlotDataItem配列を保持したまま、子の描画曲線へ渡す点列だけを変更できます。直線・左端基準の階段・単調3次曲線を選択し、曲線は [PCHIPの傾き選択](https://docs.scipy.org/doc/scipy/reference/generated/scipy.interpolate.PchipInterpolator.html)に従うHermite補間をNumPyで計算します。追加依存はありません。有限値が連続する区間ごとに補間し、元の節点を含め、外挿はしません。

1区間の分割は最大32、全体は概ね画面幅の2倍以下です。点が密集する場合や、peak間引きでXが重複している場合は補間を追加しません。表示点と元の `Trace` / Measure / Math / 保存用配列を分離し、元配列の書換は行いません。表示方式はアプリ設定とセッションのviewに保持します。

### 通常描画

- メイン波形は `WaveformViewBox` でホイールの対象をXまたはYに制限します。`OverviewViewBox` のホイールはメインのX範囲を更新し、Overview自身は全体表示を保ちます。
- `LinearRegionItem` の範囲とメインのX範囲は双方向に同期します。同期時には信号を一時停止して循環を防ぎ、範囲選択アイテムはOverviewの自動範囲計算から外します。
- アンチエイリアスを既定ONにし、`segmentedLineMode="on"` で線分をまとめて描きます。表示幅に合わせたpeak方式の間引きと `clipToView` を使い、Overviewの線はデバイス座標キャッシュを使います。描画用の点数削減であり、保存・Math・測定用の元配列は保持します。
- メイン波形とOverviewには `WaveformPlotItem` / `AdaptiveCurveItem` を使います。表示範囲の点列を画面座標の長さに換算し、線の総延長が `max(12000, 画面幅×6)` pxを超える場合はpaint中だけ1px・AAなしへ切り替えます。表示点数が少なくても長い縦線が多ければ対象です。通常描画への復帰しきい値は切替時の65%にし、境界付近の往復を抑えます。NaN前後をつながった移動として数えず、画面外の振幅・時刻は判定前にクリップします。描画後は元のペンとAA設定を戻し、元配列や設定値は変えません（[pyqtgraphの性能上の注意](https://pyqtgraph.readthedocs.io/en/latest/api_reference/graphicsItems/plotdataitem.html)）。
- A/B間隔のラベルはすぐ更新し、表と統計の更新は単発の60msタイマーでまとめます。統計はトレースと対象サンプル区間をキーにキャッシュし、表のセルも再利用します。
- Measureは選択した項目だけを、表示範囲・全体・A–B間の元サンプルから計算します。項目選択もキャッシュキーに含めます。振幅統計は有限値のみを使い、RMSは `sqrt(mean(y**2))`、AC RMSは平均値を引いたRMS、標準偏差は母標準偏差です。表示OFFのCHも表には残ります。

`measurements.METRICS` が21項目のキー・表示名・単位を定義し、`measure()` は選択されたキーの数値を辞書で返します。Low/Highは5/95百分位を初期値に、中央値による2群の反復で推定します。両初期値が同じなら元の最小／最大を使います。レベル推定のための標本は約65,536点までに制限しますが、統計・エッジの検出は範囲内の全点を使います。

`extract_edges()` は10%以下／90%以上の確定状態の変化をベクトル処理で検出し、50%交差時刻と10–90%の遷移時間を線形補間します。途中のNaN/Infを区切りとして保持し、ノイズによる50%付近の往復だけではエッジを増やしません。周期・幅・デューティ比も同じ区間内だけで計算します。タイミングの代表値は中央値を使い、周波数は代表周期の逆数です。しきい値を浮動小数点で区別できない微小振幅は測定しません。将来の復号処理からも呼べる独立関数ですが、現時点でデコーダーは実装していません。

テーマ変更は既存の曲線を維持して背景・軸・UIの色を更新します。XP風テーマはアプリ内のスタイルで、OSのタイトルバーまで置き換えるものではありません。

## Math

`expression_trace()` は式をASTで解析し、許可したノードだけを再帰的に計算します。`eval` は使いません。数式は500文字以内、定数は有限かつ絶対値 `1e100` 以下、指数は−16〜16のスカラーに制限します。波形名と `+ - * / **`、単項±、`abs / sqrt / sin / cos` を利用できます。属性アクセスや任意関数呼び出しは拒否します。

複数波形の時刻配列は形状と値の一致（小さな丸め誤差のみ許容）が必要です。結果の非有限値は `NaN` にし、すべて無効ならエラーにします。数式結果の単位は自動推定せず `arb` です。

`transform()` は等間隔サンプリングを確認してから、次を実行します。

| 操作 | 計算 | 単位 |
|---|---|---|
| 微分 | `np.gradient(y, x)` | 元単位/s |
| 積分 | 隣接2点の台形面積の累積和、先頭値0 | 元単位·s |
| 移動平均 | 端の値でパディングして均等重みの畳み込み。窓幅は点数以下に制限 | 元単位 |

`spectrum()` は3点以上・等間隔・欠損なしを条件に、全波形にHann窓を掛けて `rfft` を実行します。窓の総和で振幅補正し、DCと、偶数点数時のNyquist成分は二重に数えません。出力は片側ピーク振幅で、DC除去・RMS変換・dB変換はしません。

Mathはその時点の計算結果を独立した `Trace` として追加します。元波形との自動再計算の依存関係は持ちません。FFTは別ウィンドウに表示します。

## 実機通信

### 接続とフレーム

`DL1640` はコンテキストマネージャーで、通常は操作ごとに接続・認証し、終了時に切断します。ライブ中は `MainWindow.device_connection()` が接続を保持し、設定変更も同じ接続で直列に処理します。ライブ終了時は進行中のWorkerを待って切断し、エラー時は接続を破棄します。LOCALは保持した接続を閉じてから実行します。TCPの既定ポートは10001、タイムアウトは8秒です。VISAやTMCTL DLLは使いません。

メッセージは4バイトのbig-endianヘッダを持ち、最上位ビットが最終フレーム、残り31ビットがペイロード長です。TCPの分割受信と複数フレームを結合し、空ACKを読み飛ばします。128MiBを超えるメッセージは拒否します。ユーザー名・パスワードのプロンプトに応答し、`ready` を確認します。`decode_block()` はIEEE形式の `#<桁数><バイト長><バイナリ>` を切り出し、改行やNULをデータの一部として扱います。

### 停止中の波形取得

`capture()` は状態レジスタのbit 0で測定中でないことを確認し、次の順で取得します。

1. 機器IDと、転送用のTRACE / RECORD / START / END / DLENGTH / FORMAT / BYTEORDERを保存。
2. 最新レコード0、WORD、MSBFIRST、DLENGTH AUTOを選択。
3. 表示ONのCH1〜CH4について点数・サンプルレート・トリガ位置・RANGE・OFFSETを照会し、全サンプルを転送。
4. big-endianのint16を `y = raw × RANGE / 3072 + OFFSET`、`x = (sample_index − trigger_position) / sample_rate` に換算。raw値32767は欠損にする。
5. `finally` で保存した転送設定を戻す。途中で失敗した場合も復元を試みる。

2〜32,064,000点と正の有限サンプルレートを検証し、受信バイト数は点数×2に一致する必要があります。全CH表示OFFはエラーです。リニアスケールONの直接取得は未対応として拒否します。直接取得の `Trace.unit` は現在 `V` 固定です。電流プローブの設定入力には対応していますが、取得波形の単位ラベルは自動でAに切り替わりません。保存WVFの単位はHDRを使います。

### 設定変更と操作

`DL1640.set_display_blanked()` は[通信仕様6.28節](https://cdn.tmi.yokogawa.com/IM701610-17E.pdf)の `:SYSTEM:LCD:MODE?` で元のLCD状態を保存し、ONなら `:SYSTEM:LCD:MODE OFF` を送信します。同じ接続中は再保存しません。チェック解除・`close()` で保存した状態へ戻し、元がOFFならOFFを維持します。閉じる際の復元処理は受信タイムアウトを最大1秒にし、失敗してもソケットを閉じて警告をログへ残します。保持接続の復元失敗はQtシグナルでGUIへ通知し、Workerから直接Widgetを操作しません。HTTP画像取得にはこの操作を追加しません。

`configure_lcd()` は手動ON/OFFと明るさ1〜4を送信前に検証し、書込後に実値を照会します。手動ON/OFFは自動消灯を解除してから適用し、新しい状態を切断時に元へ戻しません。LCD操作はパネルの待ち行列で通信中も受付し、RUN/STOPと同じ単一通信Workerへ渡します。

ユーザーの接続解除は `request_live(False)` で最終取得を予約し、読み出し中ならその終了後に `DISCONNECT_CAPTURE` を実行してから保持接続を閉じます。測定条件は変更せず、DLENGTH AUTOで現在の記録の全点を取得します。確定していない単発取得は中断せず前回波形を保持します。最終元波形が同一なら既存Mathを残します。ファイルを開く・エラー処理などの内部的な `set_live(False)` は最終取得を追加しません。

`read_settings()` が本体状態、時間軸、選択CH、トリガを照会します。RUN/STOPは `toggle_run()` が操作直前に本体状態を読み、`:START` または `:STOP` を選びます。単発はSINGLE設定後にSTART、オートセットアップは `*OPC?` で完了を待ちます。LOCALは本体操作へ戻し、余計な設定照会は行いません。

`settings_commands()` は数値・SI接頭辞・単位・範囲・列挙値を検証してコマンドを生成します。全グループの値を検証したうえで、編集された項目だけに絞って送信します。CHのプローブ指定は感度・オフセットより前に送ります。トリガのソース・スロープ・レベル変更時だけSIMPLEタイプを選択し、LINEではスロープとレベルを送りません。

`apply_settings()` は送信前と各コマンド後に本体のエラーを確認し、エラーなら後続を止めます。成功後は実値を読み戻します。複数設定の変更はトランザクションではなく、途中まで適用された値の巻き戻しは行いません。

`:STATUS:ERROR?` は直前のコマンドの成否ではなく、エラーキューの古い項目から返します（[通信マニュアル7.5節](https://cdn.tmi.yokogawa.com/IM701610-17E.pdf)）。RUN/STOP・単発・オートセットアップ・波形取得の前に未読エラーを0まで読み、ログへ記録して今回の操作と区別します。最大100項目で打ち切り、不正応答や連続エラーは失敗として扱います。RUN/STOPとライブ取得で見つけた過去のエラーはステータスバーへ15秒間表示し、説明はツールチップにも残します。過去のエラーだけで操作失敗ダイアログや接続解除にはしません。

操作後に新しく発生したエラーは全項目を読み出して例外にします。START/STOPの失敗には測定状態の確認を案内し、設定の再読込を一律には要求しません。波形取得・転送設定の復元後にも確認し、そのエラーを次のSTARTの失敗として表示することを防ぎます。エラーを消すための `*CLS` や、原因不明のSTARTの自動再送は行いません。

### パネルの自動同期とWorker

`InstrumentPanel` は確認済み設定と未送信の変更を分けて持ちます。未読込状態の値は送りません。タブを開く、接続先を確定する、CHを選び直すと自動で設定を読みます。編集後250msの待ち時間を置いて変更項目をまとめます。読み戻しではWidgetの信号を抑止し、受信値を再送しません。通信中に行われた新しい編集は残し、次の送信へまとめます。

状態欄は `StatusLabel` で3行分の固定高を予約します。横方向のsize hintをレイアウトから外し、長いメッセージがパネル幅・下の操作欄の位置に影響しないようにします。全文はツールチップに保持し、フォント変更時だけ予約高を再計算します。

`QuantityControl` は直接入力のほか、長押しで繰り返す±ボタンを持ちます。T/div・感度は基本1–2–5刻み、オフセット・レベルは感度/10、遅延はT/div/10、位置は0.1div刻みです。微調整で刻みをさらに1/10にします。レコード長はDL1640の対応値だけを列挙した選択式です。F1.08の高分解能中にはレコード長書込で自動RUNになることがあるため、`apply_settings()` は書込前の測定状態を確認し、元がSTOPなら書込後にSTOPへ戻してから実値を読み込みます。高分解能状態を照会し、最大の選択肢を8M/4Mへ切り替えます。

`MainWindow.network()` は一度に1個の `Worker(QThread)` のみを動かし、通信をGUIスレッドから分離します。結果・失敗・終了をQtのシグナルで受け取り、GUI側で表示を更新します。エラー時は未送信変更と読込済み状態を破棄して再確認を促します。終了時は通信や保留中の設定反映が終わるまでウィンドウを閉じません。

## ライブ更新

`capture_live()` は実機の開始時の状態を読み、次のように動きます。

| 本体の状態 | 取得処理 |
|---|---|
| STOP | そのまま `capture()`。RUNにしない |
| 通常のRUN・プレビュー優先 | RUN中に転送設定・メタデータを準備 → STOP・最大2秒状態確認 → バイナリ転送 → `finally` でSTART → 配列変換・転送設定復元 |
| SINGLE / NSINGLEの取得中 | 中断せず待機結果を返す。次回また確認 |
| 「測定を中断しない」またはAPIで `allow_pause=False` を指定したRUN | STOP/STARTを送らず、理由 `running` の待機結果を返す |

一時停止後に転送が失敗してもRUN復帰を試み、復帰できなかった場合は明示的にエラーにします。連続ストリーミングではなく、測定の隙間と平均化のリセットが生じます。

GUIは通信終了後に、目標周期から今回の通信経過時間を引いた残りを待ちます。既定は100msで、転送が周期を超えた場合は待ち時間0です。並列要求や要求の蓄積を避けます。同じCH構成なら曲線の `setData()` で配列だけ差し替え、色・表示状態・ズームを保持します。時間軸が合わなくなった場合は元配列から全体に合わせます。

接続の操作と測定の操作を分け、48px以上のRUN/STOPボタンとSpaceキーで実機を操作します。RUN/STOPだけは通信中も有効にし、毎フレームのbusy切替で点滅させません。同じ状態のボタンへのテキスト・スタイル再設定も避けます。`QShortcut` は自動リピートを無効にし、文字入力欄では通常のSpace入力を優先します。

`queue_run_toggle()` は読み出しを中断せずにRUN/STOPを予約し、`network_finished()` が通常の設定反映・次の取得より先に `RUN_TOGGLE` を送ります。操作時点の確認済み状態または既存の操作目標から、次に要求する状態を決めます。転送後のRUN復帰が完了してから `set_running()` が実状態を確認し、必要な場合だけSTART/STOPを送ります。STOP待機中に単発が自然に完了した場合にも、既に停止している本体を再開しません。同じ待ち区間で2回切り替えた要求は相殺し、待ち行列を無制限に伸ばしません。接続先変更・通信エラーでは予約を破棄します。オフラインの波形表示中に測定操作をしても、自動で波形表示へ接続し直したり、未保存の波形を置き換えたりはしません。

停止後の最終フレームを受信すると `_stopped_frame_valid` を立てます。以後の `capture_live(capture_stopped=False)` は状態だけを読み、STOPのままなら `reason="stopped"` の待機結果を返して波形転送を省略します。これにより停止中のMath・ズーム・カーソルを保持し、Math操作も有効にできます。RUN再開または実機設定変更後にはこのフラグを戻し、新しい波形を読みます。

F1.08の実機ではRUN中の最新・履歴の `WAVEFORM:SEND?` と通常の `IMAGE:SEND?` が空ブロックを返しました。これは数値波形の取得経路で確認した制約です。HTTP画像には別の経路があり、無停止で取得できます。STOP/START応答自体にも時間がかかるため、詳細な計測記録と条件は[使い方](usage.md)を参照してください。

停止・接続先変更・ファイル読み込み時には世代番号を更新します。前の世代の遅延フレームは画面に適用しません。ライブOFFでも、進行中の転送と本体状態の復元は完了させます。最後のフレームは保存できる状態で残します。

## 本体画面モード

中央の `QTabWidget` に波形解析と独立した `ScreenPanel` を配置します。画像の受信は `Trace`、Math、波形の曲線・表示範囲・カーソル・dirty状態を書き換えません。セッション保存・CSV出力・数値解析の操作は画像モード中に無効化し、画像保存とHomeは画像側へ振り分けます。

`fetch_screen()` は実機が配信する `webmonimage.png` へGETを送ります。測定制御用TCP接続は作らず、STOP/STARTや波形転送設定のコマンドも送りません。環境変数のHTTPプロキシを使わず本体へ直接接続し、必要な場合だけBasic認証を使います。別ホストへのリダイレクトは拒否します。画像は8MiB、画素数は16,777,216を上限にし、PNGシグネチャとIHDRを確認します。GUI側でも `QImage` のデコードを確認してから差し替えます。パスワードは他の機器操作と同様に保存しません。

`ScreenView` は `QGraphicsPixmapItem` を表示し、画像の縦横比を維持したフィット、原寸、ホイール拡大、ドラッグ移動に対応します。PNG保存は受信したバイト列をそのまま書き、表示上の拡大で再サンプリングしません。

画像取得も既存の単一Workerで実行します。HTTP処理前に保持中の数値波形ライブ接続を閉じ、HTTPと機器制御の同時接続を避けます。2つの自動更新は排他的です。画面更新は既定10秒で、通信時間を含む開始間隔を使います。画像用の世代番号で、モード切替・接続先変更・自動更新停止後の遅延応答を破棄します。HTTPエラーは画面更新だけを止め、既存の波形データと読込済みの機器設定を破棄しません。

## EnDatの内蔵解析

`protocols.decode()` はEnDatを内蔵デコーダーへ、それ以外をsigrokへ渡します。共通の `logic_data()` でCH時刻・欠損・しきい値を検証し、CLOCK Highのアイドルでフレームを分離します。モードはHigh半周期、応答はLow半周期の中央で判定し、遅延補正をサンプル刻みへ丸めます。CRC異常や切れた応答は注釈へ残し、元配列を変更しません。追加情報の意味付けや連続モードなどの制限と出典は [EnDat解析](endat.md) を参照してください。
