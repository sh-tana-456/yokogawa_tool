# プロトコル解析

[ドキュメント一覧](README.md) / [使い方](usage.md)

取得済みの元波形をUART・SPI・I²C・CANとして復号できます。復号処理は外部のsigrok-cli / libsigrokdecodeを使い、結果はこのソフト内の表で表示します。EnDat 2.1/2.2は追加ソフト不要の内蔵解析（実験的）を使います。設定・対応範囲は[EnDat解析](endat.md)を参照してください。

## 準備

sigrok-cli 0.7.2とlibsigrokdecode 0.5.3で検証しました。UART/SPI/I²C/CANでは外部デコーダーが必要ですが、波形表示・測定・保存は使用できます。

Arch / CachyOSでは必要に応じて次を実行します。

```bash
sudo pacman -S sigrok-cli libsigrokdecode
```

Debian / Ubuntu系ならディストリビューションの `sigrok-cli` パッケージを導入してください。PulseViewがあってもsigrok-cliが同時に入っているとは限りません。Windowsは対応する実行ファイルとデコーダー環境が必要で、未検証です。別PCでもこの追加依存を導入してください。パッケージやライブラリ自体はこのソフトに同梱しません。

インストール場所がPATHにない場合は解析画面でsigrok-cliの実行ファイルを指定します。自動インストールや、ソフト起動時の外部プログラム実行は行いません。

## 操作

1. ファイルを開くか、実機をSTOPして波形を確定します。
2. 左の「波形・解析」の「プロトコル解析 · EnDat / UART / SPI…」を押します。
3. プロトコルと信号に対応するCHを選びます。任意信号は「なし」にできます。
4. しきい値はLow/Highから自動推定するか、自動を外してCHごとに指定します。単位は元の波形と同じです。
5. ボーレート、ビット順、クロック位相などを設定し、「スナップショットを解析」を押します。
6. 開始・終了時刻、種類、内容を確認します。行をダブルクリックするとメイン波形のカーソルをその区間へ移動して拡大します。
7. 「復号結果をCSVに保存」は全件を出力します。画面の表は先頭10,000件まで表示します。

| プロトコル | 信号・設定 |
|---|---|
| UART | RX、ボーレート、5〜9データビット、パリティ、1/1.5ストップビット、極性反転 |
| SPI | CLK、MOSIまたはMISO、任意CS、CPOL/CPHA、ビット順、1〜32ビット、CS極性 |
| I²C | SCL/SDA。開始・停止、アドレス、データ、ACK/NACKを表示 |
| CAN | 論理CAN RX、ビットレート、サンプルポイント。データ・ID・CRC等の注釈を表示 |
| EnDat 2.1/2.2 | CLK/DATA、位置ビット長、アイドル間隔、遅延補正。位置・F1/F2・CRC、追加情報の生の値を内蔵解析 |

## データと制約

- この画面を開いた時点の波形を使います。後で別の波形を取得しても、開いている解析画面の入力は自動で置き換えません。
- 表示用の曲線補間・ピーク間引きは使いません。欠損のない、等間隔・同時刻・同じ点数のCHが必要です。異なる時刻のCHを勝手に補間して揃えません。
- スナップショット内の電圧としきい値を比較して論理値に変換します。サンプリング不足、ノイズ、しきい値や設定違いでは正しく復号できません。必要に応じてMathで極性を反転した波形を使えます。
- 復号はファイル入力のみです。sigrok経由でDL1640などの機器を探索・操作しません。処理は専用Workerで行い、外部プロセスのタイムアウトは30秒です。
- ライブ更新は間欠取得なので、取得間の通信は復元できません。EnDatの実信号、CAN FD固有条件、実機上の各プロトコルの全条件は検証していません。
- 検証済みの合成波形は、UART 8N1のA5、SPI Mode 0・8bit MSBのA5、I²C 7bitアドレス書込の5A、標準11bit CANフレームのA5です。実機バスから取得した既知の通信との照合は今後の検証対象です。
