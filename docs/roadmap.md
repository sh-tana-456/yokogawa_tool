# 実装済み機能と今後の拡張

[ドキュメント一覧](README.md)

UART・SPI・I²C・CANは外部sigrok-cliによる復号に対応しました。元サンプルとしきい値を入力にし、専用Workerで解析して結果表・時刻移動・CSV出力へつなげます。追加依存と検証範囲は[プロトコル解析](protocols.md)を参照してください。

## 残っている拡張

[EnDat 2.1/2.2の実験的解析](endat.md)を公開資料とTIの実装をもとに追加しました。位置・フラグ・CRC・追加情報の生の値を扱います。実信号での照合、MRS履歴の追跡、コマンド省略の連続モード、複合コマンドの補助ペイロード、追加情報の意味付けは今後の課題です。

現在のプロトコル解析は静止したスナップショットを対象にしています。DL1640のライブ更新は間欠取得で、取得と取得の間に流れた通信は復元できません。実機バスから取得した既知の通信と、復号結果の詳細な照合も今後の課題です。

取得点数の変更機能は、ユーザー指定で今回スキップしています。切断時には本体の記録長を増やして再測定せず、現在の測定条件のまま最後の記録を全点取得します。
